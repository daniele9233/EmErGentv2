# @emergent/config

Configurazioni condivise di tooling per il monorepo EmErGent.

| Export                                         | Contenuto                                                    |
| ---------------------------------------------- | ------------------------------------------------------------ |
| `@emergent/config/eslint/base`                 | Config ESLint flat base (TypeScript type-checked + Prettier) |
| `@emergent/config/eslint/react`                | Layer ESLint per package React (react + rules of hooks)      |
| `@emergent/config/prettier`                    | Configurazione Prettier di workspace                         |
| `@emergent/config/tsconfig/base.json`          | Preset TypeScript per package Node/isomorfi                  |
| `@emergent/config/tsconfig/react-library.json` | Preset TypeScript per librerie React                         |

Questo package non ha step di build: i sorgenti sono la distribuzione.
